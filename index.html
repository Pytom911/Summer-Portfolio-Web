Tentang saya

Halo, saya PytomDev, frontend developer dari Jakarta yang suka hal yang tenang dan cepat. Saya mengubah ide kasar jadi antarmuka rapi yang enak dipakai di semua layar.

Tiga tahun saya merilis produk, dari dashboard surf school sampai pemesanan kafe dan toko keramik. Saya terobsesi dengan Core Web Vitals, kode bersih, dan aksesibilitas. Hari saya ikut pasang surut, sketsa pagi, bangun siang, rilis sebelum senja. Sekarang saya eksplor pertemuan desain produk dan performa web.
